# Check if tidytransit package is available

Tests whether the tidytransit package is installed. Used to control
example execution for functions that require tidytransit.

## Usage

``` r
mobdb_has_tidytransit()
```

## Value

Logical. `TRUE` if tidytransit is available, `FALSE` otherwise.

## Examples

``` r
mobdb_has_tidytransit()
```
